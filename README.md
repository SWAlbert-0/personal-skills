# personal-skills

Personal collection of reusable, cross-platform agent skills.

## Skills

| Skill | Description |
| --- | --- |
| [visual-tutorial-html](visual-tutorial-html/SKILL.md) | 将项目、文档或知识点制作成图文结合的单文件 HTML 学习教程 |

## Usage

将所需技能目录复制到所用 Agent 支持的项目级或用户级技能目录。各技能的具体用法以其 `SKILL.md` 为准。
